# My Personal Portfolio

Website portofolio pribadi yang dikembangkan untuk menampilkan profil, keterampilan, pengalaman, sertifikat, serta proyek yang pernah dikerjakan selama menempuh studi di Program Studi S1 Pendidikan Teknologi Informasi Universitas Negeri Surabaya (UNESA).

## Deskripsi

Website ini berfungsi sebagai media personal branding dan dokumentasi hasil pembelajaran, proyek akademik, serta pengalaman yang relevan di bidang teknologi informasi dan pengembangan perangkat lunak.

## Fitur

- Halaman Beranda (Home)
- Profil Pribadi (About Me)
- Daftar Keterampilan (Skills)
- Pengalaman dan Pencapaian (Experience)
- Daftar Proyek (Projects)
- Sertifikat (Certificates)
- Kontak dan Media Sosial (Contact)
- Tampilan Responsif

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Struktur Proyek


## Proyek yang Ditampilkan

### Website Sistem Informasi Akademik (SIAKAD)
Aplikasi berbasis web yang mendukung pengelolaan data akademik sekolah, meliputi manajemen siswa, guru, jadwal pelajaran, absensi, dan nilai akademik.

### PPDB (InSchool)
Aplikasi desktop berbasis VB.NET yang dirancang untuk membantu proses Penerimaan Peserta Didik Baru (PPDB) secara digital dengan fitur pengelolaan data pendaftar dan laporan.

### Domatio Cafe Ordering System
Aplikasi desktop berbasis Java Swing yang digunakan untuk mengelola pemesanan makanan dan minuman pada cafe secara terkomputerisasi.
